# 内容目录使用说明

这里是整个网站**唯一需要你手动维护的地方**，代码永远不用碰。

| 位置 | 内容 | 怎么更新 |
|---|---|---|
| `stats.json` | 聊天统计数据 | **不要手改**，运行 `pipeline/gen_stats.py` 自动生成 |
| `members.json` | 人物档案（头像、座右铭、学校等） | 手动编辑，格式见 `members.README.md` |
| `timeline/*.md` | 大事记 | 一个事件一个文件，文件名 `日期-标题.md` |
| `memes/*.md` | 名场面/梗百科 | 一个梗一个文件 |
| `photos/` | 照片原图 | 直接拖进来，按子文件夹分类（如 `2026-06-聚会/`），构建时自动压缩发布 |

## timeline / memes 文件格式

```markdown
---
title: 标题
date: 2026-06-08
---
正文，支持 **加粗**、换行、列表和图片：![说明](photos/子文件夹/图片.jpg)
```

写完 `git push`，几分钟后网站自动更新。
