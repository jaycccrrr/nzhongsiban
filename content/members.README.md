# 人物档案

每个对象字段说明（都可以留空，留空就不显示）：

- `id`：英文标识，用于个人页网址（`/members/tonghe/`），**定下来就不要改**
- `name`：姓名（必须和 stats.json 里的发言者名字一致，否则数据对不上）
- `avatar`：头像文件路径，如 `photos/avatars/tonghe.jpg`（把照片放到 `content/photos/avatars/` 下）
- `motto`：座右铭 / 一句话介绍
- `school`：大学 / 学校
- `city`：城市
- `intro`：自由介绍文字（支持多行）
- `tags`：自定义标签数组，如 `["班草", "球王"]`，会显示在自动生成的数据标签前面
